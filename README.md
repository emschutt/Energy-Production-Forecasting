# Energy-Production-Forecasting

The objective is to build a complete end-to-end machine learning pipeline to predict hourly energy production for 15 solar power plants, and to evaluate whether machine learning models can outperform a given benchmark

1. Install dependencies:

```bash
pip install -r requirements.txt

```

2. Run the analysis:
   Open `project_VClean_2.ipynb` in Jupyter or VS Code.
